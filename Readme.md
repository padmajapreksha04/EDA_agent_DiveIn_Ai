# 🔬 Automated EDA and Data Cleaning Agent

An intelligent research assistant powered by Google Gemini AI with real-time web search capabilities.

![Python](https://img.shields.io/badge/python-3.9+-blue.svg)
![Streamlit](https://img.shields.io/badge/streamlit-1.28+-red.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## 🌟 Features

- 🔍 **Real-time Web Search** - Powered by Serper.dev API
- 🤖 **AI Responses** - Using Google Gemini 1.5 Flash/Pro
- 🔢 **Calculator** - Built-in mathematical calculations
- 💬 **Chat Interface** - Beautiful, user-friendly Streamlit UI
- 📊 **Context-Aware** - Uses search results for accurate answers
